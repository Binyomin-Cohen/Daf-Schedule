# My Daf

A personal Shas schedule. Set how many dapim you learn on the days you choose, see them on a calendar, and click the daf you’re up to when you fall behind. The rest of the plan rebuilds from today. Your place, pace, and study days are saved in this browser.

```bash
npm install
npm run dev
```

Today’s cycle is read from the [Shas.org Daf Yomi API](https://www.shas.org/daf-yomi-api/api-documentation.html). Scanned pages open through the [Daf PDF API](https://www.shas.org/daf-pdf/api/api-documentation.html).
